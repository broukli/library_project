# Проблемы хранения данных в оперативной памяти:
1. Все данные теряются при остановке приложения
2. Данные существуют только во время работы процесса
3. Ограниченный объем оперативной памяти ( 1 книга ~1kb - 1,000,000 книг - 1gb)
4. Медленная работа при большом количестве данных
5. Отсутствие персистентности 
- Нет механизма сохранения на диск 
- Нет резервного копирования 
- Нет восстановления после сбоев
6. Проблемы с параллельным доступом 
- Возможны race conditions
7. Масштабируемость
- Невозможно масштабировать горизонтально
- Каждая копия приложения имеет свою копию данных
- Нет синхронизации между экземплярами

# Преимущества и недостатки файлового хранения
## Преимущества:
1. Главное преимущество человекочитаемость
2. Широкая поддержка и универсальность (не нужно искать сторонние библиотеки)
3. Простота использования
4. Идеален для конфигураций
5. Иерархическая структура данных
## Недостатки:
1. Отсутствие схемы и типизации (не можете на уровне формата требовать обязательное поле)
2. Низкая эффективность (размер и скорость)
3. Ограниченный набор типов данных (строки, числа, булевы значения, null, объекты и массивы)
4. Плохая поддержка комментариев
5. Не подходит для больших и сложных данных
6. Проблемы с параллельным доступом и атомарностью
